# 页知项目背景目录

本目录用于保存页知（PageCue）的长期产品背景、竞争边界和已经确认的迭代计划，避免产品讨论散落在会话、演示稿和代码注释中。

## 当前文档

- [产品介绍与项目背景](./pagecue-product-background.md)
- [P0 整体迭代计划](./pagecue-p0-iteration-plan.md)

## 使用约定

- 产品定位、用户范围和明确不做的内容以“产品介绍与项目背景”为准。
- 准备开发、评审、测试和上线时，以“P0 整体迭代计划”为准。
- 后续如果产品判断发生变化，应同步更新背景文档并记录日期，不能只修改代码。
- 内容库的选题、审核和批量导入工作流不属于本次 P0，由后续独立工作流负责。
