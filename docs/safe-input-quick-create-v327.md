# 页知 3.2.7：输入框选词创建提醒

在网页普通单行文本框或搜索框中选中字符后，可以右键选择“页知：创建提醒”。

安全规则：

- 只读取用户实际选中的字符，不读取完整输入框。
- 每个关键词必须为 2–20 个字符。
- `/` 和 `／` 继续拆分为多个 OR 关键词，每个关键词分别计算长度。
- 选区包含换行时直接拒绝，不自动拼接。
- 只允许无类型、`text` 和 `search` 输入框。
- 密码、邮箱、手机号、验证码、Token、用户名等敏感字段继续拦截。
- 同一表单中存在密码框时，即使当前字段是文本框也会拦截。
- `textarea` 和富文本编辑器继续拦截。

普通成员只能创建个人提醒；具有组织发布权限的管理组成员可以选择全员提醒。服务端重复验证关键词长度和换行限制，不能通过修改客户端请求绕过。
