# 页知 3.2.1 侧边栏与悬挂窗口

## 目标

1. Chrome、Edge 和具备 `chrome.sidePanel` 能力的浏览器支持“自动、侧边栏、悬挂窗口”三种打开方式。
2. 搜狗及不支持侧边栏的 Chromium 浏览器自动使用悬挂窗口，不显示不可执行的假能力。
3. 两种模式复用 `sidepanel/index.html`，提醒、评论、链接、定位、个人提醒、同步、工具箱和设置能力保持一致。
4. 侧边栏随浏览器拖动宽度自适应；窄宽度下不产生横向溢出，并提供页知内的一键隐藏按钮。
5. 模式切换只在设置变更、扩展启动和用户点击时执行，不增加网页扫描、定时轮询或后台常驻请求。

## 验收标准

- 默认模式为 `auto`；支持侧栏时解析为 `sidepanel`，否则解析为 `popup`。
- 设置中可选择三种模式，并明确显示浏览器实际采用的模式。
- 选择悬挂窗口后，下次点击扩展图标打开 `sidepanel/index.html` 弹窗。
- 选择侧边栏后，下次点击扩展图标打开同一个 `sidepanel/index.html` 侧栏。
- 不支持侧栏时选择“侧边栏”会自动降级到悬挂窗口并提示用户。
- 快速隐藏在支持 `sidePanel.close()` 时直接关闭；旧内核使用禁用后恢复面板的兼容路径；弹窗使用 `window.close()`。
- 三个主入口 `alerts`、`memos`、`tools` 在两种模式下均存在。
- UI最小适配宽度不高于280px，并针对360px以下宽度压缩间距。
- 侧栏应用和后台模式控制不使用 `setInterval`，不创建第二套UI。
- 构建后Chrome/Edge包保留 `side_panel`，搜狗包保留 `action.default_popup`。
- 相对3.2.0的压缩安装包增量目标不超过5KB；若超出，必须给出文件级原因。
