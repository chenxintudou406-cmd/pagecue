# 页知 3.2.6：选中文字快速创建提醒

## 使用方式

1. 在普通网页中选中一段文字。
2. 右键选择“页知：创建提醒”。
3. 补充标题和备注，可切换知识/操作、轻/中/重及生效页面。
4. 点击“创建提醒”后立即同步，并重新匹配当前页面。

选中文字中的 `/` 或 `／` 会拆成多个 OR 关键词。

## 权限

- 普通成员只能创建“仅自己”的提醒。
- 管理员或所属成员组开启“允许发布全员提醒”后，可选择“全体成员”。
- 权限由服务端根据邀请码绑定的成员身份和当前分组判断，不能通过修改客户端请求绕过。
- 线上已有“管理组”会保留原 ID，只开启发布权限，不自动调整任何成员的分组。

## 默认值

- 提醒类型：知识提醒。
- 提醒程度：轻。
- 关键词关系：OR。
- 生效页面：全部网页。
- 操作提醒有效期：从创建时开始，30 天后到期。

从 3.2.7 开始，安全的单行文本框和搜索框允许只使用实际选中的 2–20 个字符创建提醒；敏感字段、换行、文本域和富文本仍会拦截。PDF、Word、Excel 和图片 OCR 不属于本版本。
